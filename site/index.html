Warnung beim ersten Start? Das ist normal.

WeintCompanion ist ein kleines Gildenprojekt. Ein Zertifikat, mit dem Windows und macOS das Programm sofort als „bekannt“ einstufen, kostet jedes Jahr Hunderte Euro – das haben wir nicht. Darum fragt dein Computer beim ersten Start nach. Danach nie wieder, und auch Updates laufen ohne Nachfrage direkt in der App.

Windows
  1. Öffne WeintCompanion-Setup.exe aus deinen Downloads.
  2. Erscheint „Der Computer wurde durch Windows geschützt“: klicke auf Weitere Informationen und dann auf Trotzdem ausführen.
  3. Folge dem Installer. Fertig.
Der Download wurde blockiert oder die Datei ist verschwunden? Dann hat dein Virenscanner sie vorsichtshalber in Quarantäne geschoben. Im Browser kannst du unter den Downloads Beibehalten wählen; bei Windows Defender stellst du sie unter Windows-Sicherheit → Viren- & Bedrohungsschutz → Schutzverlauf wieder her. Schalte deinen Virenscanner dafür bitte nicht ab. Wenn du unsicher bist, frag im Discord nach.
macOS
  1. Öffne WeintCompanion-macOS.dmg und zieh WeintCompanion in den Ordner Programme.
  2. Starte WeintCompanion. macOS meldet, dass es nicht geöffnet werden kann – klicke auf Fertig (nicht „In den Papierkorb“).
  3. Öffne Systemeinstellungen → Datenschutz & Sicherheit, scrolle nach unten und klicke bei WeintCompanion auf Dennoch öffnen. Bestätige mit deinem Passwort.
Klappt das nicht? Öffne das Programm Terminal und füge diese Zeile ein, dann Enter:
xattr -cr /Applications/WeintCompanion.app
Danach startet WeintCompanion normal. Intel-Macs werden leider nicht unterstützt.
Linux
  1. Rechtsklick auf WeintCompanion-x86_64.AppImage → Eigenschaften → „Als Programm ausführen“ erlauben (oder chmod +x WeintCompanion-x86_64.AppImage).
  2. Doppelklick zum Starten.

Fragen? Melde dich im Gilden-Discord.
