Der erste Start

Dein Computer fragt beim ersten Öffnen einmal nach, ob du WeintCompanion vertraust. Das ist normal – so kommst du in einer Minute weiter.

  1. Öffne WeintCompanion-Setup.exe aus deinen Downloads.
  2. Erscheint „Der Computer wurde durch Windows geschützt“: klicke auf Weitere Informationen und dann auf Trotzdem ausführen.
  3. Folge dem Installer – fertig. Updates kommen ab jetzt in der App.
Download blockiert oder Datei verschwunden? Dein Virenscanner hat sie vorsichtshalber in Quarantäne geschoben. Im Browser kannst du unter den Downloads Beibehalten wählen; bei Windows Defender stellst du sie unter Windows-Sicherheit → Viren- & Bedrohungsschutz → Schutzverlauf wieder her. Bitte schalte den Virenscanner dafür nicht ab – frag im Zweifel im Discord.
  1. Öffne WeintCompanion-macOS.dmg und zieh WeintCompanion in den Ordner Programme.
  2. Starte WeintCompanion. macOS meldet, dass es nicht geöffnet werden kann – klicke auf Fertig (nicht „In den Papierkorb“).
  3. Öffne Systemeinstellungen → Datenschutz & Sicherheit, scrolle nach unten und klicke bei WeintCompanion auf Dennoch öffnen. Bestätige mit deinem Passwort.
Klappt das nicht? Öffne das Programm Terminal, füge diese Zeile ein und drück Enter:
xattr -cr /Applications/WeintCompanion.app
Danach startet WeintCompanion normal. Intel-Macs werden leider nicht unterstützt.
  1. Rechtsklick auf WeintCompanion-x86_64.AppImage → Eigenschaften → „Als Programm ausführen“ erlauben (oder chmod +x WeintCompanion-x86_64.AppImage).
  2. Doppelklick zum Starten – fertig.

Warum die Nachfrage? WeintCompanion ist ein Gildenprojekt. Das Zertifikat, mit dem Windows und macOS ein Programm sofort als „bekannt“ einstufen, kostet jedes Jahr Hunderte Euro. Der Quellcode ist öffentlich auf GitHub einsehbar.
